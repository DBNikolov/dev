### 1. Top Paying Data Analyst Jobs
To identify the highest-paying roles, I filtered data analyst positions by average yearly salary and location, focusing on remote jobs.

``` sql
SELECT 
    job_id,
    job_title,
    name AS company_name,
    job_location,
    job_schedule_type,
    salary_year_avg,
    job_posted_date
FROM job_postings_fact
LEFT JOIN company_dim
    ON company_dim.company_id= job_postings_fact.company_id
WHERE job_location = 'Anywhere' 
    AND job_title_short= 'Data Analyst'
    AND salary_year_avg IS NOT NULL
ORDER BY salary_year_avg DESC
LIMIT 10; 
```
- Salaries range from $184,000 (Get It Recruit) to $650,000 (Mantys), creating a $466,000 gap within a 10-job sample.

- Removing the single $650,000 Mantys listing drops the top-10 mean salary from $264,506 to $221,682—a 16.2% reduction.

- Executive/Director roles account for 30% of the sample, Principal/Lead roles account for 30%, and generic or specialized individual contributors account for 40%.

- Employer Density: Financial services, health systems, and tech majors (Meta, Pinterest, SmartAsset) dominate the upper tier of compensation.

### 2.What skills are required for these top-paying jobs?

To understand what skills are required for the top-paying jobs, I joined the job postings with the skills data.

```sql
WITH top_paying_jobs AS (
    SELECT 
        job_id,
        job_title,
        name AS company_name,
        job_location,
        salary_year_avg
    FROM job_postings_fact
    LEFT JOIN company_dim
        ON job_postings_fact.company_id = company_dim.company_id
    WHERE job_location = 'Anywhere' 
        AND job_title_short= 'Data Analyst'
        AND salary_year_avg IS NOT NULL
    ORDER BY salary_year_avg DESC
    LIMIT 10
)

SELECT 
    top_paying_jobs.*,
    skills
FROM top_paying_jobs
JOIN skills_job_dim ON top_paying_jobs.job_id = skills_job_dim.job_id
JOIN skills_dim ON skills_job_dim.skill_id = skills_dim.skill_id
ORDER BY salary_year_avg DESC;
```
#### Analysis:

- **SQL**: Required by 100% of roles (8/8 jobs).

- **Python**: Required by 87.5% of roles (7/8 jobs).

- **Tableau**: Required by 75% of roles (6/8 jobs).

- **R**: Required by 50% of roles (4/8 jobs).

- **Snowflake / Pandas / Excel**: Each required by 37.5% of roles (3/8 jobs).

- **Cloud & Enterprise Platforms**: Azure,AWS,Oracle,Power BI,Go,and Atlassian toolchains(Jira/Confluence/Bitbucket) each appear in 25% of listings (2/8 jobs).

### 5. What are the most optimal skills to learn?

Combining high demand with high salaries helped isolate the most strategic skills for entry and advancement in data analytics.

Compared two results for skills when priority is high salary and when priority is high number of job postings.

```sql
--RESULTS BASED ON THE JOB POSTINGS AS A PRIORITY.

SELECT 
    skills_dim.skill_id,
    skills,
    ROUND(AVG (salary_year_avg),0) AS avg_salary,
    COUNT (job_postings_fact.job_id) AS total_jobs
FROM job_postings_fact
JOIN skills_job_dim ON job_postings_fact.job_id = skills_job_dim.job_id
JOIN skills_dim ON skills_job_dim.skill_id= skills_dim.skill_id
WHERE 
    job_title_short = 'Data Analyst' AND
    salary_year_avg IS NOT NULL
GROUP BY skills,skills_dim.skill_id
ORDER BY total_jobs DESC,avg_salary DESC
LIMIT 10;

/*
RESULTS BASED ON HIGH SALARY AS A PRIORITY. 
(ADDITIONAL FILTER WHERE NUMBER OF JOBS POSTINGS IS HIGHER THAN 35 IS ADDED HERE TO AVOID ANOMALIES OF JOBS WITH VERY HIGH SALARY BUT ONLY FEW POSTINGS.)
*/

SELECT 
    skills_dim.skill_id,
    skills,
    ROUND(AVG (salary_year_avg),0) AS avg_salary,
    COUNT (job_postings_fact.job_id) AS total_jobs
FROM job_postings_fact
JOIN skills_job_dim ON job_postings_fact.job_id = skills_job_dim.job_id
JOIN skills_dim ON skills_job_dim.skill_id= skills_dim.skill_id
WHERE 
    job_title_short = 'Data Analyst' AND
    salary_year_avg IS NOT NULL
GROUP BY skills,skills_dim.skill_id
HAVING COUNT (job_postings_fact.job_id) > 35
ORDER BY avg_salary DESC,total_jobs DESC
LIMIT 10;
```

### 6. What are the most paying jobs and their skills across the whole dataset and not only for data analyst positions?

Here we are not focusing on Data Analyst positions but trying to explore the whole set of jobs.

Sorting the highest paying jobs overall and then finding the skills associated with them.

```sql
SELECT 
    job_title_short,
    ROUND(AVG (salary_year_avg),0) AS avg_salary
FROM job_postings_fact
WHERE salary_year_avg IS NOT NULL
GROUP BY job_title_short
ORDER BY avg_salary DESC;

SELECT 
    skills,
    COUNT (job_postings_fact.job_id) AS jobs_count
FROM job_postings_fact
JOIN skills_job_dim
        ON job_postings_fact.job_id = skills_job_dim.job_id
JOIN skills_dim
        ON skills_job_dim.skill_id = skills_dim.skill_id
WHERE
    (job_title_short = 'Data Scientist' OR
    job_title_short = 'Senior Data Scientist' OR
    job_title_short = 'Machine Learning Engineer' OR
    job_title_short = 'Data Engineer' OR
    job_title_short = 'Senior Data Engineer') AND
    salary_year_avg IS NOT NULL
GROUP BY skills
ORDER BY jobs_count DESC
LIMIT 10;
```

1. **Top-paying data analyst jobs:** High-tier salary distributions in the sample are in a big range and skewed toward executive leadership and major tech/finance employers, where removing a single $650,000 outlier reduces the top-10 average pay by 16.2%.

2. **Skills for top-paying jobs:** Core data handling skills like SQL, Python, and Tableau dominate job requirements across the vast majority of roles, while cloud platforms and enterprise toolchains serve as secondary qualifications.

3. **Most required skills:** The set of skills required for data analyst does not change based on the type of job.

4. **Skills with higher salaries:** Remote postings offer more predictable salary bands and lean heavily toward Data Science, Data Engineering, and asynchronous tooling, showing only minimal overlap with the niche infrastructure tools found in broader listings.
Specialized skills,such as SVN and Solidity, are associated with the highest average salaries.

5. **Optimal skills based on salary and demand:** General BI and entry-level analyst skills (like SQL and Python) establish the baseline requirement for resume screening, whereas specialized data engineering tools (like Kafka and Airflow) act as key drivers for high-paying senior roles.
SLQ is also positioned very good in the high demand area but also offers decent average salary.

6. **Required skills based on all jov postings:** Senior data science and engineering roles dominate the top salary tier (ranging from ~$127k to $154k), driven by overwhelming market demand for foundational programming languages (Python, SQL) and big data cloud infrastructure (AWS, Spark).

#### Closing thoughts
This analysis underscores the importance of a dual-track skill strategy for data professionals: focus on mastering foundational, high-demand tools (SQL, Python, Visualization) to secure market viability, while selectively upskilling in high-paying specializations (Cloud, Big Data) to maximize earning potential.
